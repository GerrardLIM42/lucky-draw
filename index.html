최근 당첨

    지금은 예시 명단과 상품이에요. 설정에서 참석자, 사진, 상품을 바꿔 주세요.

    당첨을 축하합니다
    상품

    당첨자 명단

    복사한 명단은 엑셀이나 메신저에 바로 붙여넣을 수 있어요

    사진 맞추기

    사진을 끌어서 위치를 옮기고, 막대나 마우스 휠로 크기를 맞추세요. 파란 테두리 안이 당첨 화면에 그대로 나와요.

    명단·당첨자 목록의 동그라미

    키보드 화살표로 조금씩 옮길 수도 있어요.

    추첨을 처음부터 다시 할까요?

    참석자 명단, 사진과 사진 위치, 상품은 그대로 남아요. 결과가 필요하면 먼저 '당첨자' 명단에서 복사해 두세요.

    준비된 명단과 사진 열기

    이 사이트에는 암호로 잠긴 참석자 명단과 사진이 들어 있어요. 행사 담당자에게 받은 암호를 입력해 주세요. 한 번 열면 이 컴퓨터에서는 다시 묻지 않아요.

    설정

    참석자 명단

    한 줄에 한 명씩, 또는 쉼표로 구분해 붙여넣으세요. 이름이 같은 분은 김민수(영업)처럼 구분하고, 사진 파일 이름도 똑같이 맞춰 주세요.

    참석자 사진

    사진 파일 이름을 참석자 이름과 같게 저장해 두세요. 예: 김민준.jpg, 김민준_영업팀.png

    사진 파일을 여기로 끌어다 놓거나

    사진 칸을 누르면 당첨 화면에 나올 위치와 크기를 맞출 수 있어요. 사진이 없는 칸을 누르면 한 장씩 넣을 수 있어요.

    등수와 상품

    위에서부터 차례로 추첨해요. 낮은 등수를 위에 두면 1등이 마지막에 나옵니다. 왼쪽 네모를 누르면 상품 사진을 넣을 수 있어요.

    사진등수상품명인원

    저장과 초기화

    명단, 사진, 상품, 당첨 기록은 이 브라우저에 저장돼서, 같은 컴퓨터에서 다시 열면 그대로 이어져요. 다른 컴퓨터에서 쓰려면 아래 '준비 파일'로 옮겨 주세요.

    다른 컴퓨터로 옮기기

    명단, 사진과 사진 위치, 상품을 파일 하나로 저장했다가 행사용 노트북에서 불러오면 그대로 이어서 쓸 수 있어요.

    사이트에 명단과 사진 담기

    지금 명단, 사진과 사진 위치, 상품을 담은 index.html 파일을 만들어요. GitHub 저장소에서 Add file → Upload files로 이 파일을 올리면, 사이트 주소로 여는 사람 누구나 같은 내용으로 시작해요.

    암호를 걸면 사이트에는 잠긴 상태로 저장되고, 암호를 아는 사람만 컴퓨터마다 한 번 입력해서 열 수 있어요. 비워 두면 사이트 주소를 아는 누구나 명단과 사진을 볼 수 있어요.
