# 럭키드로우 회전판

송년회 경품 추첨용 회전판입니다. 브라우저에서 바로 열리고, 로그인이나 설치가 필요 없습니다.

- 참석자 명단, 사진(파일 이름 = 참석자 이름), 등수별 상품을 설정에서 넣습니다.
- 준비한 내용은 그 브라우저에 저장됩니다. 다른 컴퓨터로 옮길 때는 설정 → 옵션 → '준비 파일 저장/불러오기'를 씁니다.
- 스페이스바, Enter, PPT 리모컨 '다음' 버튼으로 추첨하고 당첨을 확인합니다.
- 설정 → 옵션 → '사이트용 파일 만들기'로 명단·사진을 담은 index.html을 만들어 이 저장소에 올리면, 사이트를 여는 누구나 같은 내용으로 시작합니다. 암호를 걸면 저장소와 사이트에는 잠긴 상태로만 저장되고, 암호를 아는 사람만 열 수 있습니다.
